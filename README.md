# 🌊 Flood Safety AI

ระบบวิเคราะห์ภาพพื้นที่น้ำท่วม ประเมินระดับน้ำและความเสี่ยงอัตโนมัติด้วย **Groq Vision AI (LLaMA 3.2)** พร้อมระบบยืนยันตัวตนด้วย **Firebase Auth**

## 🚀 Stack ที่ใช้
- **Frontend**: HTML5, Tailwind CSS, JavaScript (ES6+), Firebase Auth Web SDK
- **Backend**: Python, FastAPI, Uvicorn, Groq API (Vision), Firebase Admin SDK
- **Development Tool**: Acode App on Android
